# Zepto SQL Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing Zepto product data using SQL to explore product pricing, discounts, product availability, and inventory insights.

## 🛠️ Tools & Technologies
- PostgreSQL
- SQL

## 📊 Project Work

### 1. Data Exploration
- Retrieved total number of records.
- Identified NULL values.
- Explored different product categories.
- Analyzed in-stock and out-of-stock products.
- Identified duplicate product names.

### 2. Data Cleaning
- Identified products with zero prices.
- Removed products with zero MRP.
- Converted prices from paise to rupees.

### 3. Data Analysis
- Found the top 10 products with the highest discount percentage.
- Identified high-MRP products that are out of stock.
- Calculated estimated revenue for each category.
- Found products with MRP above ₹500 and discounts below 10%.
- Identified top 5 categories with the highest average discounts.
- Calculated price per gram for products.
- Categorized products based on weight using CASE statements.
- Calculated total inventory weight per category.

## 💡 SQL Concepts Used
- SELECT, WHERE, ORDER BY
- DISTINCT
- GROUP BY and HAVING
- Aggregate Functions (COUNT, SUM, AVG)
- CASE Statements
- UPDATE and DELETE
- ROUND and LIMIT
